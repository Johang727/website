Premise

I got tired of needing to switch to Windows for color or duplex prints, so I needed to find a way to actually get this working natively without a VM.

The built in printing front-end never worked for me, perhaps you have more success with it, however, it always gave B/W prints or none at all. Furthermore I would need to reconfigure printers all the time.

The printers have all been changed to FollowMe Printers, therefore, the previous setup.sh no longer works and the setup has changed. Driverless printing makes it weird, and I have not managed to get prints to work with the GUI, only in CLI.

After some research, I found this neat script I plan on adding a print from PDF option to in the future.

Without further ado, let's get into the setup.

Dependencies

Most Linux Distros like Linux Mint, Ubuntu, etc. come with these by default. Arch distros typically do not have these installed. Regardless, make sure you have cups and samba installed on your computer using your package manager.

Printer Setup

Clone the GitHub Repo: https://github.com/Rewzilla/pc-mobility-print, someone already made a program to add those FollowMe printers.

In the username and password, enter your Doane University credentials. Do not include @doane.edu.

Under server, enter ob2 and under domain, enter doane.local. There is no error detection built into the software, so if it locks up for more than 10 seconds, restart the program and try again.

Add the FollowMeColor printer, there is no reason to use the BW since you can just send a BW print to the color queue. And that's it. Depending on your specific flavor of Linux, you'll need to print from the terminal. To do that, envoke lp -d "FollowMeColor" -o sides=two-sided-long-edge -o print-color-mode=color for a color + double sided print. Modify the command to suit your needs. Double check the print details on the printer to make sure it's what you want.
